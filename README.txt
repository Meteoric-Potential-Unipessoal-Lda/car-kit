МАГНИТОЛА-НАБОР (car-kit) 0.2 — проверка и оптимизация Android-магнитол по ADB
(FYT / UIS7862 / UIS8581 / UIS7870 — Teyes, Joying, Mekede, Hizpo; QF; Topway TS10 / TS18;
 Rockchip PX5 / PX6 MTCD / MTCE — Dasaita, Pumpkin, Xtrons, Eonon; дешёвые MTK (Reglink, HCN);
 Allwinner T3 / T5 / T8; ATOTO и любые другие Android-магнитолы)
Сделан по образцу phone-kit: та же страница в браузере, 10 языков, план с галочками, откат по журналу.

ЧТО НОВОГО В 0.2
  - Экран магнитолы на ноутбуке (scrcpy): кнопка «Экран магнитолы» на странице или start.bat -Mirror.
    Управление мышью прямо через AnyDesk: сам нажимаешь «Разрешить», проверяешь радио и камеру.
    Звук не перехватывается — остаётся в колонках машины. scrcpy качает prepare.bat (или набор при первом нажатии).
  - Снимок настроек магнитолы (только чтение) в отчёте raw\unit: все настройки Android, свойства платформы,
    у FYT — /oem/app/config.txt (модель машины, CAN) и список /oem/app. Пригодится после сброса/прошивки.
  - Проверки: сбитые часы (ломают Google Play/карты), выключенное авто-время, выключенная геолокация,
    слабый Wi-Fi до точки доступа.
  - Свои приложения: положить .apk в папку apk\ — в плане появятся пункты «Установить ...» (не отмечены);
    откат удаляет только то, что поставил набор.
  - Для тестеров: TESTING.md и шаблон «Отчёт о проверке» на GitHub.

ГЛАВНОЕ ПРАВИЛО — НЕ НАВРЕДИТЬ
  Слой производителя магнитолы под защитой целиком: MCU, CAN-шина, радио, Bluetooth-телефон,
  камера заднего хода и 360, кнопки руля, звук/DSP, CarPlay/Android Auto (ZLink, AutoKit...),
  сон по ACC, рабочий стол, настройки и заводское меню. Пакеты com.syu.*, com.fyt.*, com.qf.*,
  com.tw.*, com.microntek.*, com.hct.*, com.reglink.*, com.hcn.*, com.atoto.* и т.п. набор
  трогает ТОЛЬКО если они есть в нашем проверенном списке data\car.tsv (ok / ask).
  Всё, что работает от имени системы (sharedUserId android.uid.system), — тоже не трогаем.
  После каждой партии проверяется, живы ли службы магнитолы (com.syu.ms, com.qf.framework,
  com.tw.car, android.microntek.service, com.reglink.services...). Упала — откат партии и стоп.

ИНТЕРФЕЙС
  start.bat (Windows) / start.command (Mac) открывает страницу в браузере (127.0.0.1, без интернета).
  Отвечать можно и на странице, и в окне консоли. Только консоль: start.bat -Console
  Языки: русский, українська, English, Português, Español, Français, Italiano, Deutsch, Latviešu, Polski.

ОДИН РАЗ У СЕБЯ
  prepare.bat — кладёт в tools\ ADB для Windows и Mac и PowerShell для Mac
  (если рядом лежит папка tv-kit или phone-kit — берёт всё оттуда).

В МАШИНЕ
  1. Машина стоит, зажигание включено; лучше с заведённым двигателем (магнитола не уснёт, АКБ не сядет).
  2. Спросить владельца: чем пользуется (радио, штатный плеер с флешки, CarPlay/Android Auto,
     DVR, TPMS, голосовой помощник, Google Play, YouTube) — это пункты «спросить», не отмечены.
  3. На магнитоле: Настройки -> «Об устройстве» -> 7 раз «Номер сборки» -> «Для разработчиков» ->
     «Отладка по USB». Подключить магнитолу к Wi-Fi — обычно к точке доступа телефона клиента.
     Ноутбук — к той же сети.
  4. Запустить набор (AnyDesk на ноутбуке клиента или свой ноутбук). Набор сам ищет магнитолу
     в сети (порт ADB 5555). Нашёл — на экране магнитолы нажать «Разрешить» («Всегда»).
     Не нашёл — подсказка H: где включить ADB по сети, пароли заводского меню (3368, 8888, 126, 1234...;
     набор их НЕ подбирает), Android 11+ — код сопряжения (W), IP вручную (I, порт 5555 сам).
     В заводском меню ничего, кроме ADB, не менять (модель машины, CAN, экран, MCU)!
  5. Пункт 2 «Оптимизация»: диагностика -> план с галочками. Обычно Enter -> «да».
     Номер пункта ПЕРЕКЛЮЧАЕТ галочку.
  6. Проверить руками с клиентом: рабочий стол, радио, Bluetooth (звонки и музыка), камеру заднего
     хода, кнопки руля, звук, CarPlay/Android Auto, навигацию, данные CAN (климат/двери).
  7. Перезагрузка с проверкой. Магнитола сама вернётся в Wi-Fi, набор найдёт её (по старому
     адресу и сканом сети). На многих прошивках ADB по сети после перезагрузки выключается —
     тогда набор скажет и надо проверить результат глазами (журнал отката сохранён).
  8. В конце: если владельцу не нужно — выключить «Отладку по USB» / ADB по сети. Закрыть окно,
     удалить папку car-kit у клиента. Архив и backups\ — забрать к себе.

ЧТО В ПЛАНЕ
  - Анимации 0.5x (отмечено).
  - Мусор из базы UAD и нашего списка: реклама/аналитика (Facebook-заглушки, Google Feedback/Analytics),
    Adups FOTA (известный сбор данных на дешёвых MTK), китайские сервисы Kuwo/QQ Music/Ximalaya.
    Отмечено только явное; приложения Google (YouTube, Chrome, Карты, приложение Google), штатные
    плееры, радио, эквалайзер, большие часы FYT, голосовой помощник — «спросить владельца».
  - «Не усыплять в фоне»: навигация (Waze, Яндекс, 2ГИС, Google Карты, Sygic...), музыка (Spotify,
    Яндекс Музыка...), CarPlay/Android Auto — исключение из оптимизации батареи (отмечено, обратимо).
  - Фон: сторонние приложения, которые не открывали месяц, но висят в памяти (навигация, музыка,
    DVR, OBD, лаунчеры не трогаются).
  - Частный DNS AdGuard (не отмечено), очистка кэша (если память заполнена >85%).

ПОДСКАЗКИ В ДИАГНОСТИКЕ
  - Платформа и чип (FYT/Teyes/ATOTO, QF, Topway TS, MTCD/MTCE, Reglink, HCN, NWD, Allwinner;
    UIS7862 / UIS8581 / UIS7870, PX5 / PX6 / PX30, MTK, Qualcomm).
  - «Магнитола показывает Android 13, а на деле Android 10» — частая подмена версии.
  - Навигация/музыка закрывается после выключения зажигания — это «убийца приложений» прошивки;
    совет по платформе (белый список FYT, Quick boot у Reglink, Malaysk у MTCD...).
  - MediaTek DuraSpeed включён, ADB по сети открыт постоянно, root в ADB, Google тяжёл для 2 ГБ.

ОСОБЫЕ СЛУЧАИ
  - Android Automotive (Volvo, Polestar, Renault с Google): только диагностика, ADB обычно закрыт.
  - Teyes и UIS7870: другая разметка прошивки — заранее отмечается только проверенное.
  - Платформа не распознана: набор спросит и работает в осторожном режиме.
  - Телевизор/приставка — tv-kit, телефон — phone-kit.

ПРИСЛАТЬ CLAUDE АРХИВ (C:\cleanmytv\reports)
  - первая магнитола новой платформы или «не распознана»;
  - красные/жёлтые строки, магнитола не вернулась после перезагрузки, что-то перестало работать;
  - жалобы владельца, которые набор не объяснил.

ЕСЛИ ЧТО-ТО ПЕРЕСТАЛО РАБОТАТЬ
  Пункт 3 «Откат» — вернёт всё по журналу (можно выборочно). Магнитола не загружается — подождать
  5–10 минут, кнопка Reset (иголкой) или выключить/включить зажигание, потом пункт 3.
  Сброс к заводским и прошивку НЕ делать.

ФАЙЛЫ
  carkit.ps1    — сам набор (PowerShell 5.1 в Windows, PowerShell 7 на Mac)
  data\car.tsv  — наш список пакетов магнитол: protect / ask / ok (сильнее любых правил)
  data\uad.tsv  — база Universal Android Debloater Next Generation (GPL-3.0)
  data\ru.tsv   — общие пометки (из phone-kit);  data\lang\ — 10 языков;  ui\ — страница
  reports\      — отчёты;  backups\ — журналы отката;  tools\ — ADB и PowerShell для Mac
