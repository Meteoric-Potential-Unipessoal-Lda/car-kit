Папка apk — свои приложения для установки на магнитолу (навигация, плеер, лаунчер...).
Положите сюда файлы .apk — в плане оптимизации появятся пункты «Установить ...» (не отмечены).
Ставятся только по галочке; откат (пункт 3) удаляет то, что поставил набор. Рабочий стол набор не меняет.
car-launcher.apk — наш лёгкий рабочий стол (собирается на GitHub). Отметьте «…сделать домашним», если владелец хочет.
Берите APK только из надёжных источников (сайт разработчика, GitHub-релизы).

apk folder — your own apps to install on the head unit. Put .apk files here; the plan will show unchecked
"Install ..." items. Rollback (option 3) removes what the kit installed. Use APKs from trusted sources only.
